# CIS-240

Small C++ class examples. Each folder is its own CMake project with a short README.

- [Class Intro](classintro/) — a simple `Counter` class
- [First Objects](FirstObjects/) — rectangles, prisms, and object lifetimes
- [Polys](Polys/) — polynomial terms and evaluation
- [Chapter 14](ch14/) — copying, moving, and operator overloading

Build any example with CMake (C++17). Generated build folders and IDE settings are not tracked.
